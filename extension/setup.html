A ONE-TIME SETUP

Your downloads.
On your computer.

YT Drop uses a small Windows helper to run yt-dlp. Once it’s connected, you can save a video or extract its audio directly from the extension.

  1. Install the local helper

    Extract the YT Drop repository. In its main folder, run install.ps1 using PowerShell. The installer checks for Python, FFmpeg and a supported JavaScript runtime and prints the extension’s folder.

    If setup reports a missing dependency, follow the full guide above, open a new PowerShell window and try again.

  2. Load the right folder in Chrome

    Open chrome://extensions, enable Developer mode, and choose Load unpacked. Select the installed extension folder printed by setup. It must contain manifest.json directly.

    Usually: %LOCALAPPDATA%\YTDrop\extension. Don’t select the repository’s outer folder.

  3. Choose a video and save it

    Pin YT Drop from Chrome’s Extensions menu. Open a YouTube video and click YT Drop, or paste a video link. Choose Video or MP3 Audio, then Download. You can close the panel while it runs; keep Chrome open.

A little help when you need it

Setup needed? After installing the helper, reopen the extension and click Retry connection. Keep the original manifest key so the extension can connect to its helper.

Updating? Get the latest repository files and rerun the installer with Chrome closed. Reopen Chrome and reload YT Drop on its Extensions page. Reloading an extension interrupts active downloads.

Download interrupted? Open the error details for the actual yt-dlp message. Check that the video is available. YT Drop does not sign in, import browser cookies or bypass access restrictions. Playlists and active live broadcasts are not supported.

A slow transfer? Fast mode uses up to eight parallel fragments where supported. Try Standard if it stalls, or choose a lower video resolution. Conversion and merging can still take time.

Where is my file? Use the folder arrow in YT Drop. Downloads are saved by the helper and won’t appear in Chrome’s Downloads list. Video usually uses MKV; audio uses MP3.

Need a different folder? Rerun the installer with -DownloadDirectory 'D:\Videos'. Existing downloads stay where they are.

Use with videos you own or have permission to download. Independent of YouTube and yt-dlp.
